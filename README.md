✅ TO-DO Website

A simple, intuitive, and user-friendly To-Do List Web Application designed to help users organize their daily activities, manage tasks, and improve productivity.

🚀 About the Project

The TO-DO Website is a task management application that allows users to create, manage, and track their daily tasks in one place.

It provides a simple interface to organize work, maintain productivity, and keep track of completed and pending activities.

✨ Features

* ➕ Add Tasks – Easily create new tasks.
* ✏️ Edit Tasks – Update task details whenever needed.
* 🗑️ Delete Tasks – Remove tasks that are no longer required.
* ✅ Mark as Completed – Track completed activities.
* 📋 Task Management – Organize daily activities efficiently.
* 📱 Responsive Design – Accessible across different screen sizes.
* 🎨 Simple UI – Clean and user-friendly interface.

💻 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

git clone https://github.com/SATHYA182907/TO-DO-file-1.git

2. Navigate to the Project Folder

cd TO-DO-file-1

3. Run the Project

Open the HTML file in your preferred web browser.

Alternatively, use the Live Server extension in VS Code.
